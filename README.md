# Cottonmouth Habitat Selection Analysis

This repository contains the R code, data-management workflow, statistical analyses, tables, and figures used for the Cottonmouth (*Agkistrodon piscivorus*) habitat-selection project and associated *Herpetological Conservation and Biology* manuscript. The analysis code was originally extracted from the Kauphusman thesis and subsequently updated and revised for the current manuscript.

## Project Overview

The project evaluates habitat selection by Cottonmouths relative to available habitat and examines potential differences in habitat use among demographic groups. The analytical workflow includes:

* Data import and preparation
* Hydrologic data visualization
* Principal Component Analysis (PCA)
* PERMANOVA and PERMDISP
* Comparisons among Cottonmouth demographic groups
* Linear regression of body size and PCA scores
* Random forest habitat-selection models
* Model performance assessment using accuracy, Kappa, sensitivity, specificity, out-of-bag accuracy, and AUC
* Variable-importance analysis
* Partial dependence plots
* Generation of manuscript-ready figures and tables

The primary Cottonmouth dataset is stored in the `data/` directory as `Cottonmouth-Datasheet.csv`. Additional hydrologic data from USGS monitoring stations are also read from the `data/` directory. Figures generated by the analysis are written to the `HCB_figs/` directory.

## R Package Environment and `renv`

This project uses **`renv`** to manage the R package environment and improve reproducibility.

The project-level `renv` environment is intended to record the specific package dependencies used by the analyses rather than relying on whatever package versions happen to be installed in a user's global R library. This is particularly important for this project because the analysis depends on numerous R packages for multivariate statistics, random forests, model evaluation, tables, and graphics.

The analysis currently uses packages including `caret`, `raster`, `data.table`, `vegan`, `permute`, `sp`, `dplyr`, `ggplot2`, `tidyr`, `knitr`, `lattice`, `MASS`, `randomForest`, `randomForestExplainer`, `ROCR`, `cowplot`, `ggrepel`, `gt`, `glue`, `pdp`, `scales`, `kableExtra`, and `patchwork`.

### Restoring the project environment

After cloning or downloading the repository, open the R project and restore the package environment with:

```r
renv::restore()
```

`renv::restore()` uses the project's `renv.lock` file to install the package versions recorded for the project rather than using your global R package library.

### Updating the lockfile

When package dependencies are intentionally added, removed, or updated, the current state of the project library can be recorded with:

```r
renv::snapshot()
```

The resulting changes to `renv.lock` should be committed to version control along with relevant changes to the analysis code.

Thus, **Git tracks the project code and the `renv.lock` file, while `renv` tracks the R package dependencies needed to reproduce the computational environment**. The installed package library itself should not be treated as part of the analysis source code.

If locally installed or locally developed R packages are used, their treatment by `renv` should be checked before updating the lockfile to ensure that the recorded package source accurately reflects how the package can be restored on another computer.

## Analysis Workflow

The analysis is organized approximately as follows:

1. Load required R packages and establish the plotting theme.
2. Import the Cottonmouth and hydrologic datasets.
3. Generate hydrology figures.
4. Prepare habitat variables and remove correlated predictors.
5. Conduct PCA of habitat characteristics.
6. Compare Cottonmouth locations with available habitat using PERMANOVA and PERMDISP.
7. Examine habitat differences among demographic groups.
8. Evaluate relationships between body size and PCA scores.
9. Fit and evaluate random forest habitat-selection models.
10. Calculate variable importance.
11. Generate partial dependence plots for influential habitat variables.
12. Export manuscript figures and tables.

Random forest models use fixed random-number seeds where appropriate to improve reproducibility of model fitting and train/test partitioning.

## Reproducing the Analysis

For a new installation of the project:

```r
# Restore the recorded package environment
renv::restore()
```

Then run or knit the primary R Markdown analysis file. Required input datasets should retain the directory structure expected by the code, particularly the `data/` directory. Output directories such as `HCB_figs/` should also exist before figures are exported.

## Reproducibility

Reproducibility for this project relies on three components:

**Code** — analysis and figure-generation scripts are maintained under version control.

**Data** — analyses reference project-relative paths such as `data/Cottonmouth-Datasheet.csv` rather than machine-specific absolute paths.

**R environment** — `renv` records the package dependencies and package versions associated with the project in `renv.lock`.

Together, these allow the analytical workflow to be reconstructed on another computer using the project files, required data, and the package environment recorded by `renv`.
